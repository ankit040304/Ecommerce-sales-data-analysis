E-Commerce Sales Data Analysis

Project Overview

This project focuses on analysing e-commerce sales data to identify business trends, evaluate sales performance, understand customer purchasing behaviour, and generate actionable business insights.

The project follows an end-to-end data analytics workflow, covering data extraction, cleaning, transformation, exploratory data analysis, SQL-based analysis, and interactive dashboard development.

Objectives

- Analyse overall sales and revenue performance.
- Identify monthly and yearly sales trends.
- Evaluate product and category performance.
- Understand customer purchasing behaviour.
- Analyse order trends and delivery performance.
- Generate meaningful insights to support data-driven business decisions.

Tools & Technologies

- Python: Data analysis and preprocessing
- Pandas: Data manipulation and cleaning
- NumPy: Numerical operations
- SQL (MySQL): Data querying and analysis
- Power BI: Interactive dashboard development and data visualization
- Microsoft Excel: Data inspection and validation

Project Workflow

1. Data Collection: Obtained and explored the e-commerce dataset.
2. Data Cleaning: Handled missing values, duplicates, and inconsistencies using Python.
3. Data Analysis: Performed exploratory data analysis (EDA) using Pandas and NumPy.
4. SQL Analysis: Used SQL queries, joins, aggregations, and analytical functions to extract business insights.
5. Data Visualization: Developed interactive dashboards in Power BI to monitor key performance indicators (KPIs) and sales trends.
6. Business Insights: Identified important patterns in revenue, customer behaviour, product performance, and order delivery.


Key Analysis Areas

- Revenue and Sales Performance
- Monthly and Yearly Sales Trends
- Product and Category Analysis
- Customer Behaviour Analysis
- Order and Delivery Performance
- Key Performance Indicators (KPIs)

Dataset

The project uses the Brazilian E-Commerce Public Dataset by Olist.

Dataset Source: "Olist Brazilian E-Commerce Dataset – Kaggle" (https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

Project Outcome

The analysis provides insights into e-commerce sales performance, customer purchasing patterns, product trends, and operational metrics through data analysis and interactive visualizations.
